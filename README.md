# git 사용법
1. 로컬 저장소를 생성한다.
2. 코드를 작성한다.
3. 변경내역에 대해 커밋(버전)을 생성한다.
   * 변경사항을 git이 자동으로 감지한다.(.gitignore에 등록된 파일/디렉토리 제외)
   * 커밋으로 남길 변경사항을 스테이징영역에 추가한다.
   * 커밋 메시지와 함께 커밋을 생성한다. ㅎㅎ
